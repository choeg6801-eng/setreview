# 셋리뷰 SetReview

> 셋리스트를 완벽하게 예습하고, 벅찬 여운을 영원히 복습하는 가장 스마트한 방법.

록 페스티벌·내한 공연·뮤직 페스티벌을 찾아다니는 음악 덕후를 위한 셋리스트 예습·복습 서비스예요. 랜딩 페이지와 실제로 동작하는 웹앱이 함께 들어 있어요.

- **랜딩 페이지** `/` — 서비스 소개와 출시 알림 신청
- **웹앱** `/app/` — 아래 기능이 모두 동작해요

## 기능

| 기능 | 설명 |
|---|---|
| 공연 찾기 | 진행 중 · 다가오는 · 지난 공연, 검색, 페스티벌 · 내한 공연 필터 |
| 일정 자동 수집 | KOPIS(공연예술통합전산망)에서 국내 페스티벌 · 내한 공연을 매일 자동으로 가져와요 |
| 내 공연 기록 | 다녀온 공연을 연도별로 기록하고 요약 · 월별 막대 · 목록으로 한눈에 |
| 취향 맞춤 | 좋아하는 아티스트 · 장르 등록, 본 아티스트 · 장르 자동 집계, 맞춤 공연, 아티스트 추천 |
| 알림 | 알림함 + 메일(좋아하는 아티스트 공연 즉시 · 주간 모음 · 티켓 오픈 하루 전 · 1시간 전) |
| 공연 소식 | 매일 기사 · 공식 발표 수집(초안) + 사용자 공연 제보 → 운영자 검토 후 공개 |
| 예상 셋리스트 | 무대별 예상 순서, 곡마다 음악 앱 링크 (Spotify · Apple Music · YouTube Music · 멜론 · 라이브 영상) |
| 하이라이트·떼창 구간 | 곡 타임라인 위에 구간 표시, 떼창 지수 (멤버십) |
| 내 공연 | 담은 공연의 D-day, 예습 진행률, 하루 권장 예습량 |
| 실시간 싱크 | 공연 중 지금 부르는 곡, 부른 곡 목록, 깜짝 곡 표시 — 화면이 자동으로 갱신돼요 |
| 현장 제보 | "지금 이 곡"과 "여기서 떼창!" 제보 → 운영자가 승인하면 반영 |
| 복습 카드 | 실제 셋리스트로 인스타그램 스토리 크기 이미지 생성 · 공유 |
| Spotify 저장 (베타) | 예상·실제 셋리스트를 Spotify 플레이리스트로 저장 (테스터 5명) |
| 멤버십 | 월 12,000원, 토스페이먼츠 자동결제, 무료 베타 스위치 |
| 운영자 화면 | 공연·무대·곡·떼창 구간 등록, 예상 셋리스트 편집, 라이브 진행, 제보 처리, 출시 알림 CSV |

## 바로 써 보기

설정 없이 배포하면 **데모 모드**로 열려요. 데이터는 각자의 브라우저에만 저장돼요.

1. `/app/` 접속 → 로그인 → **덕후 데모 계정**으로 공연을 담고 예습을 체크해 보세요.
2. 다른 탭에서 **운영자 데모 계정**으로 로그인 → 운영 → 라이브 진행에서 곡을 추가하면, 첫 탭의 공연 화면이 실시간으로 바뀌어요.

로컬에서 보려면 이 폴더에서 `npx serve .` 를 실행하고 `http://localhost:3000/app/` 를 열어요.

## 실제 서비스로 열기

[docs/SETUP.md](docs/SETUP.md)에 단계별로 정리했어요.

1. **Supabase** 연결 → 카카오·구글 로그인, 공용 데이터베이스, 실시간 업데이트
2. **Spotify 베타** → 테스터 플레이리스트 저장
3. **토스페이먼츠** → 월 12,000원 멤버십 자동결제

## 기술 구성

- 빌드 과정 없는 정적 웹앱 (HTML · CSS · 자바스크립트 모듈) → Vercel 정적 배포
- Supabase: Postgres 데이터베이스, 행 단위 권한(RLS), 소셜 로그인, Realtime, Edge Functions(결제)
- 결제: 토스페이먼츠 자동결제(빌링) API v2
- 음악: 음악 앱 링크 + Spotify Web API (2026년 2월 개발 모드 변경 사항 반영)

## 저작권 안내

- 아티스트명·곡명·앨범 아트는 예시이며 권리는 각 권리자에게 있어요.
- Spotify는 Spotify AB의 상표예요. 셋리뷰는 Spotify 또는 아티스트와 제휴 관계가 아니에요.
- 배경 음악과 예시 커버 일러스트는 셋리뷰를 위해 새로 만든 오리지널이에요.
