# 셋리뷰 SetReview — 랜딩 페이지

> 셋리스트를 완벽하게 예습하고, 벅찬 여운을 영원히 복습하는 가장 스마트한 방법.

록 페스티벌·내한 공연·뮤직 페스티벌을 찾아다니는 음악 덕후를 위한 셋리스트 예습·복습 앱 **셋리뷰**의 출시 전 랜딩 페이지입니다. 빌드 과정 없는 정적 사이트(HTML 한 장 + 이미지·오디오)라 Vercel에 그대로 배포됩니다.

## 구성

```
index.html          랜딩 페이지 (반응형, 배경 음악 플레이어 포함)
assets/img/         공연 사진, 앨범 아트, 예시 커버
assets/audio/       배경 음악 (셋리뷰 오리지널 루프)
og-image.jpg        SNS 공유 썸네일 (1200×630)
favicon.svg         파비콘
vercel.json         정적 파일 캐시 설정
```

## 로컬에서 보기

`index.html`을 브라우저로 열면 됩니다. 또는 `npx serve .` 로 로컬 서버를 띄워도 됩니다.

## 배포 (Vercel)

1. [vercel.com/new](https://vercel.com/new)에서 이 저장소를 Import
2. Framework Preset: **Other**, Build Command·Output Directory는 비워 두기
3. Deploy

이후 `main` 브랜치에 푸시할 때마다 자동으로 다시 배포됩니다.

## 출시 전 남은 작업

- [ ] 푸터 사업자 정보(상호·대표·사업자등록번호·통신판매업 신고번호·주소) 채우기
- [ ] FAQ의 고객센터 이메일 채우기
- [ ] 출시 알림 폼을 실제 이메일 수집 서비스와 연결 (현재는 화면만 있음)
- [ ] 배포 주소 확정 후 `og:image`를 절대 주소로 바꾸기
- [ ] 이용약관·개인정보처리방침 페이지 연결

## 저작권 안내

- 아티스트명·곡명·앨범 아트는 시안용 예시입니다. 앨범 아트의 저작권은 각 아티스트와 음반사에 있습니다.
- Spotify는 Spotify AB의 상표입니다. 셋리뷰는 Spotify 또는 아티스트와 제휴 관계가 아닙니다.
- 배경 음악과 예시 커버 일러스트는 셋리뷰를 위해 새로 제작한 오리지널입니다.
